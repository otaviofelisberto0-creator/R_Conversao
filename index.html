Criterio fixo BL: NM_MARCA = NET; NM_PERFIL_CLIENTE = todos; NM_TIPO_ASS_DOMICILIO = DADOS, DADOS + VOZ, VIDEO + DADOS ou VIDEO + DADOS + VOZ. Utiliza as mesmas datas D-1 e D-2.
